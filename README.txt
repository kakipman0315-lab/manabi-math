# まなびAI 数学チャレンジ（無料試作版）

## 入っている機能
- 自然な日本語のお願い文から、問題数・時間・学年・難しさ・テーマを簡易的に読み取る
- 算数の四則演算、分数、一次方程式、連立方程式、因数分解の一部を自動生成
- タイマー、採点、解説、端末内TOP 10ランキング
- PWA用 manifest / service worker / アイコン

## 大切なこと
これは**オンラインのChatGPTを接続したものではありません**。入力文を端末内のルールで読み取って問題を生成する無料版です。自由な会話で何でも理解する本物のAI機能はまだありません。APIキーや課金は不要です。

## スマホで使う
1. ZIPを展開して `index.html` などのファイルを取り出す。
2. まずは `index.html` をブラウザで開いて試せます。ただし、ホーム画面へのインストールやオフライン対応は、HTTPSで公開した場合に動作します。
3. HTTPS対応の静的ホスティングサービスにファイル一式をアップロードし、公開URLをChromeで開く。
4. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選ぶ。

端末内ランキングは同じブラウザにだけ保存されます。共有ランキングにはサーバーが必要です。
